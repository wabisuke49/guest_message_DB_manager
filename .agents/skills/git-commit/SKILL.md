# Gitコミットの作成

変更内容とリポジトリの履歴を確認し、意味のまとまりごとにコミットする。

## コミットメッセージ

- 日本語で書く。
- Conventional Commitsの `<type>(<scope>): <description>` 形式にする。
- 先頭行は簡潔に「何をしたか」を書き、Issue番号やリンクを含めない。
- `Co-authored-by` を付けない。

## 手順

1. `git status`、`git diff HEAD`、現在のブランチ、直近のコミットを確認する。
2. 変更を適切な単位に分け、各コミットに含めるファイルとコミットメッセージを提示する。
3. ユーザーの明示的な確認を得てから、対象ファイルだけをステージし、コミットする。

## 安全性

秘密情報、個人情報、生成物、意図しない変更など、コミットに不適切なファイルを検出したら、重大な報告としてユーザーに伝え、そのファイルはコミットしない。ユーザーの変更を無断で破棄・上書きしない。
